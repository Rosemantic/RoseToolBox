## 6. Search & Discovery

- 共享搜索模块执行 NFKC、首尾去空白、连续空白折叠及忽略大小写；中文原样可检索。按空白切词、去重，所有词采用 AND，可分别命中名称、描述、分类、子分类、标签和别名。
- 输入框保留用户正在输入的尾部空格和光标位置，避免连续输入多词被同步逻辑截断。URL 保存规范化查询。高亮使用安全文本节点，并保留原始字符显示。
- 标签精确筛选与搜索、分类、价格和平台取交集。首页标签操作退出临时收藏/合集入口；详情标签跳转会清除不兼容的查询、分类、价格、平台、收藏和合集状态，再应用该标签。
- 详情标签操作关闭抽屉、移除 `tool` URL 状态、更新结果计数和面包屑，并将焦点移到结果标题。键盘 Enter 与鼠标均可操作；普通 Escape 关闭仍恢复原触发按钮焦点。
- 热门标签显示前 8 项；“全部标签”以原生可展开面板展示全部 139 项，每项显示覆盖网站数。按覆盖数降序、同数按名称稳定排序，面板限制高度并可滚动。
- 搜索、标签、分类、价格、平台、合集、收藏及详情继续使用现有 URL 状态机制。实际验证过组合筛选及刷新恢复。

## 7. Recommendation Logic

评分为：同子分类 **+3**，同顶级分类 **+1**，每个不同的共同标签 **+1**。排除当前网站，排除零分；按分数降序，然后按 slug、ID 的稳定字符顺序排序，最多取 3 个。全部候选为零分时返回空列表。

浏览器和静态详情生成器共同使用 `src/discovery.js`，没有两份评分实现。标签评分先规范化、去重，避免重复标签加分。

测试覆盖评分组成、跨分类标签、重复标签、自身排除、零分、同分、顺序反转和最多 3 项。另对全部 121 个生成详情页逐页比对推荐顺序与共享算法结果，并核对静态标签跳转链接。

## 9. Importer Compatibility

导入器识别全部新分类/子分类，可处理嵌套文件夹及紧凑 Netscape HTML，识别临时目录并跳过其全部下级内容。已知元数据按新分类清理，不再自动将分类/子分类作为标签。
